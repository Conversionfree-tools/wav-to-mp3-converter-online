## Why WAV to MP3?

WAV files are typically uncompressed, which keeps full audio quality but makes them large. MP3 uses compression to make files much smaller, so they are easier to store, share, and play on almost any device. The trade-off is that MP3 is a lossy format, so keep your original WAV if you may need to edit the audio later.
